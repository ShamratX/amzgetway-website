# Site helpers

Optional files to copy into your public website (usually `/assets/` or `/cms/`).

| File | Copy to | Purpose |
|------|---------|---------|
| `cms.js` | `/assets/cms.js` | Apply branding from public CMS JSON (name, mark, logo, favicon) |
| `cms-section-nav.js` | `/assets/cms-section-nav.js` | Handle `data-cms-section` menu links |
| `page-shell.example.html` | `/cms/page-shell.html` | **Required** template for Admin “New page” builder — replace header/footer with yours |

Full instructions: [`../docs/04-connect-your-website.md`](../docs/04-connect-your-website.md)
